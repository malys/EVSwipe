Release v1.4.1

Summary
- Adopt EVSuite design system: shared tokens, adaptive launcher icon, Material3 DayNight themes with WCAG-compliant light/dark colors.
- Repair GitHub issue templates and add DESIGN.md.
- Add CI security gates and dual-channel release workflows (stable/unstable), with a permission allowlist that blocks unexpected permission drift.
- Align the repo with the EVSuite: application id change, two-channel builds (stable/unstable), OTA updater only in unstable, updater checks APK signature before install.
- UX & stability fixes: rename ABRP_Uploader -> EVABRPUploader, UI tweaks, bugfixes and various doc improvements (CONTRIBUTING, DISCLAIMER, SECURITY, AGENTS).

Details
- Design & Assets: EVSuite tokens applied, adaptive vector-only launcher icon, 64 dp targets.
- Channels: stable builds contain no INTERNET/updater code; unstable includes OTA updater behind BuildConfig.OTA_ENABLED.
- Security/CI: release.yml runs the security gates and only publishes from v* tags; unstable pre-release on pushes to master.
- Default target: follows EVLauncher (com.evsuite.launcher).
- Documentation: added DESIGN.md, updated README.md and suite-standard docs for contributors.
